# Weekly Review Archive

This folder stores final weekly org summaries after user review and, when applicable, Slack posting.

## Naming

Use one file per review:

```text
YYYY-MM-DD.md
```

Use the date shown in the summary title. If multiple summaries are produced on the same date, add a short suffix such as `YYYY-MM-DD-revised.md`.

## How To Use

- Future weekly summaries may read recent archive entries for trend context.
- Always sync and summarize from the live `snapshot/` files first; the archive is context, not source of truth.
- Archive the exact final text that was approved for posting, not intermediate drafts.
- Keep formatting Slack-friendly so archived summaries remain easy to repost or compare.
