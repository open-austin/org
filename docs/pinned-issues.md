# Pinned Issues
This doc is for unresolved Open Austin org/tooling/process issues we are intentionally preserving for later.

"Put a pin in it" means: do not solve this right now, but do not let it vanish into chat history either. Capture the issue, current context, and the moment when it should be revisited.

This is not a backlog for ordinary GitHub issues, board tasks, automation bugs, or implementation details. Use it for unresolved concerns, questions, or tradeoffs where the right next step depends on future org usage, GitHub platform behavior, another spike landing first, or clearer project context.
